# ReelTone · 光学声轨档案工作台

ReelTone 将现成光学声轨边带的透光图案按扫描行解读为监听音频。它把原始像素位置、读片设置、齿孔定时、监听快照和图像证据保存在一个本地工作库中。播出的内容可以回到源扫描核对，并在一个有摘要的交付包内交接。

## 启动

运行 `./start.sh` 后打开 [本地工作台](http://127.0.0.1:19955/)。Compose 默认只绑定回环地址，并把数据库放在 `archive-library` 命名卷中。使用 `docker compose stop` 停止服务，工作库保留。设置 `REELTONE_PORT` 可选择另一空闲端口。要复用本机已有的兼容依赖镜像，可给定 `REELTONE_DEPENDENCY_IMAGE`，构建仍按 `requirements.txt` 核查版本。

Python 3.11 环境也可安装 `requirements.txt` 后运行 `python -B -m reeltone`，默认地址 `127.0.0.1:8000`。设置 `REELTONE_DATA` 可选择工作库位置，`HOST` 与 `PORT` 可调整服务地址。建议保留独立本地库；导出的审听包不是整个工作库的数据库备份。

## 读片和交付

1. 点击「载入合成练习」，或新建档案卷后导入扫描。合成练习包括码头口述和夜间渡轮各三张不同状态的声轨，声音为定量生成的测试音色。首次从「码头口述 · 首次扫描」开始。源文件有单张与 ZIP 批量预检，两者都会识别原始字节重复。批量 ZIP 内的 `intake.json` 可用 `{"scans":{"strip.png":{"title":"保管标题","note":"扫描说明","direction":"reverse"}}}` 推荐初始走片方向。
2. 从左栏打开扫描。单击全幅缩图定位，拖动主图可在原片坐标框选，单击主图设置像素探针。原片起止范围包含起始行，停止行是区间上界。打开「技术资料」可见文件编码、原片摘要和几处码值样本。角标与框线始终引用未翻转的原片位置。
3. 在「配方」设置声轨读窗、齿孔带、明暗参考和走片。手动行速或稳健齿孔代表间距用来建立播放时间。读片配方一经保存形成历史版本。查看或复制旧配方不会重写先前保留的监听。
4. 在「监听」填原片行区间，点击「生成监听」预听，用波形回到对应的原片行。「保存监听快照」保留 WAV、范围、读片版、时间和输出设置。在「记录」打开快照，可以检查来源、复算或标记已复核。同一扫描可用两份快照做 A/B 对听。
5. 「巡检」有透光轮廓、齿孔间距、监听频谱、曝光图、局部瑕疵、横向接片候选、匹配扫描对照、光学读窗查找、图像裁片、像素近邻、基准音和截面漂移等工具。保存图像证据后可下载保留的 PNG 和读数 JSON。精确裁片还保留未转向、未缩放的灰度像素。原片联排提供 PNG 与 A4/Letter 打印 PDF。
6. 需要拿尺子在纸上核对同一批胶片的两处边带时，用「物理倍率联排」：在每张扫描旁填它的每毫米像素数（不用文件内嵌 DPI），把两幅裁片编成一组；每组占一页 A4，最多两组。可改横竖纸与左右并排/上下叠放，各组共用同一个纸面:原片倍率。倍率放不下时会先列出冲突组与超出量，并给出同一排版可用的最大等比倍率；按建议值重新预览后才生成 PDF。页面左下与右中带 1/5/10 mm 纸面标尺，裁片四边标原片列行号，题注列出原片毫米与纸面毫米；预览 PNG 与 PDF 使用同一栅格。打印时须选实际大小（100%），不要选“适合页面”。
6. 夜间渡轮的「反差参照」中，原图最右边有五个合成的曝光阶。最上、中央及最下三阶已知相对透射分别为 0.08、0.48、0.87。开启阶梯透射标定可评估曲线和读数残差。码头口述的首次扫描在行 4210 到 7400 中保留约 455 Hz 基准音，适合检查频率读数。
7. 「审听与交付」可查看每张图已有监听覆盖、补备注、保存审听标记和检查哪些标记已有完整复核。交付的监听取明确指定的已复核快照。可以选择完整监听或其中一个原片标记，指定播放次序并附显式间隔。包内有独立 WAV、可选串听 WAV、来源行区间表、选择的证据和可选原始扫描。接收端可对 ZIP 逐文件核验。

## 材料和读数约定

- 导入 PNG、单页 TIFF 或 JPEG，支持无透明通道的灰度 8/16 位或 RGB 8 位。索引色与一位灰度会展开为工作码值。工作平面的 RGB 亮度采用固定通道加权，保留文件自带色彩标签供复核。源文件顺序与字节不变，工作台可正反走片和左右镜像。胶片沿行走片，横向扫描须先在扫描流程中转正。
- 输入上限为单张 32 MiB、2,048 列、44,000 行、1,400 万像素。ZIP 累计最多 58 MiB、2,700 万像素和 14 张图。单次试听最多 20 秒，串听最多 90 秒。保留完整扫描和多个来源的 ZIP 交付包最多 62 MiB。
- 宽度监听读取跨列透光的分数像素宽度。平均码值监听适合对已知所选单轨做相对强度检查。视频裁边、实际放映同步、双轨复用和独立音频修复工程无需由本工具完成；这里只保存来自选定图像带的单声道监听。
- 齿孔计时使用全片的代表孔距和输入帧率，报告偏差和可疑缺孔。没有足够的已确认孔距时可显式选手动行速。WAV 采样率高于原始行速不会增加原片带宽。
- 轮廓、亮度和局部候选只说明图像中可测的变化。严重遮挡、亮度截断、片外物或画格边缘会使读数失去实际依据。试音检查和阶梯曲线需由可确认的扫描参考段支持。内嵌 DPI 为采集端声明，实物量测需单独核准。

光学声轨扫描恢复是已用于电影档案数字化的工作流。ReelTone 针对已经拆出的边带，采用独立实现。领域背景见 [美国国会图书馆的 DPX 说明](https://www.loc.gov/preservation/digital/formats/fdd/fdd000178.shtml) 和 [南卡罗来纳大学 AEO-Light 项目说明](https://usc-imi.github.io/aeo-light/)。
